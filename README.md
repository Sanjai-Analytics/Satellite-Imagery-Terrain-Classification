# Satellite-Imagery-Terrain-Classification
Build a convolutional neural network (CNN) to classify satellite images into different land cover types (e.g., urban, agricultural, forest, water, barren land). 

## Executive Summary
Earth observation agencies require automated computer vision to monitor deforestation, urban sprawl, and supply chain infrastructure from orbit. Leveraging operational logistics and supply chain principles to map complex geographical systems, this project deploys a PyTorch ResNet50 Convolutional Neural Network (CNN) to classify near real-time Sentinel-2 satellite imagery into 10 distinct land cover types. It features an on-demand, in-memory ETL pipeline using the Google Earth Engine (GEE) API, ensuring high-speed, zero-storage inference.
